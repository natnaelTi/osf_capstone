# Final Submission Screen Specification

## Public Landing Page

- User: Ethiopian service exporter, finance lead, product builder, judge, or ecosystem partner.
- Task: Understand the information gap and see how Wayfinder turns an official source change into a traceable action plan.
- Primary action: Enter a demo workspace or inspect the pitch deck.
- Evidence: Official authority, effective date, source relationship, freshness, and review boundary.
- Risk: Marketing language must not imply legal certainty or comprehensive coverage.
- States: Responsive layout, public evidence access, clear synthetic labels, and no login requirement for public content.

## Pitch Deck

- User: Hackathon judge or partner.
- Task: Review the problem, users, workflow, trust model, prototype, scalability, and next step.
- Primary action: Move between slides or download the submission PDF.
- States: Previous/next controls, slide counter, horizontal scroll snapping, keyboard-accessible controls, and PDF download.

## User Guide

- User: Any judge entering a demo role.
- Task: Select a role, follow its workflow, and understand what each action proves.
- Primary action: Open the appropriate role section and follow the numbered path.
- Risk: The guide distinguishes synthetic demo identities from real authentication and professional authorization.

## Freshness And Audit Updates

- Latest completed manual or scheduled agent run controls the corpus timestamp.
- Controlled fixtures never update the official-corpus timestamp.
- Agent runs show start and completion times.
- Findings show detection time in administrator, curator, and reviewer queues.
- Audit entries use full UTC timestamps.
